# Start Here

Новый проект на VibecoSwaga? Один экран — и всё ясно.

## Если ты создатель проекта

```bash
# 1. Установи vibeco (один раз в жизни)
npm i -g @vibecoswaga/cli

# 2. Создай новый проект
vibeco init my-cool-project

# 3. Запустится Claude. Скажи ему «погнали» или сразу опиши идею.
```

Дальше Claude:
- Проведёт интервью (intake)
- Напишет спеку
- Распределит работу на тебя и коллег
- Зафиксирует API-контракты
- Соберёт скелет с зелёным CI

Ты только говоришь идею в чат. Никакой git/gh не пишешь руками.

## Если тебя позвали в существующий проект

```bash
# 1. Один раз — установи vibeco (если ещё нет)
npm i -g @vibecoswaga/cli

# 2. Подключайся к репо
vibeco join git@github.com:user/project.git

# 3. Claude спросит «кто из них ты?» — выбираешь свой номер.

# 4. Запустится Claude с уже определёнными границами твоей зоны.
#    Скажи «погнали» — и поехали.
```

## Дальше — словарь команд

Тебе нужно запомнить **8 фраз** на русском. Не команд — фраз.

| Скажи Claude | Что произойдёт |
|---|---|
| `что у нас?` | покажет ветку, PR'ы, входящие запросы |
| `продолжаем` | возьмёт следующую задачу из плана и сделает через TDD |
| `отдавай` | прогонит тесты, запушит, откроет PR, включит auto-merge |
| `аппрув N` | аппрувнет PR номер N (от коллеги) |
| `стоп` | прервёт текущее действие |
| `откати последний` | откатит последний коммит (revert, не force) |
| `запроси у X Y` | создаст GitHub-issue с просьбой к коллеге |
| `синк-апдейт` | соберёт сводку для еженедельного созвона |
