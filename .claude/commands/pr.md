description: Pre-PR check + push + создать PR + auto-merge
---

Запусти `vibeco pr` (см. `playbooks/06-parallel-work.md` секция «Отдача на ревью»).

Если CLI недоступен — сделай вручную через агента `pr-checker` (`.claude/agents/pr-checker.md`):

1. **Pre-PR check:**
   - Все тесты зелёные в Docker: `docker compose -f docker-compose.test.yml up -d && pytest && npm test`
   - Линтер чистый: `ruff check . && eslint .`
   - `git fetch origin main && git rebase origin/main` (если конфликт — `playbook 08`)
   - Контракты не сломаны: `pytest tests/integration/test_contracts.py`
   - Pre-commit hook `check-boundaries.sh` не сработал (т.е. границы не нарушены)

2. **Если pre-check красный** — фикс по `playbook 09-ci-debug.md` (≤3 попытки, потом stop-rule).

3. **Push:** `git push origin <current-branch>`.

4. **Создать PR:**
   ```
   gh pr create \
     --title "feat(<slice>): <wp-description>" \
     --body "$(cat <<'EOF'
   Реализует WP-<N>.<M> из docs/plan.md.

   Затрагивает: <slice>/**.
   Контракты: не менялись (или: меняются, см. RFC-PR #X).

   <auto-generated commit list from git log>
   EOF
   )"
   ```

5. **Auto-merge:** `gh pr merge --auto --squash <PR-N>`.

6. Сообщить человеку: «PR #<N> создан, auto-merge включён.»
